# 🧩 U-Net для Решения Лабиринтов

Нейросеть на архитектуре U-Net для предсказания пути через лабиринты с возможностью перехода к реальным картам.

## 🚀 Возможности

- ✅ **Генерация "на лету"** - данные генерируются в процессе обучения, не занимают место на диске
- ✅ **4 алгоритма генерации** - Prim, Kruskal, Eller, Aldous-Broder
- ✅ **Разные размеры** - поддержка лабиринтов от 33x33 до 77x77 (и более)
- ✅ **Аугментация данных** - вращения и отражения для улучшения обобщения
- ✅ **Валидация** - отдельная выборка для контроля переобучения
- ✅ **Early Stopping** - автоматическая остановка при отсутствии улучшений
- ✅ **Learning Rate Scheduler** - косинусный или plateau scheduler
- ✅ **Mixed Precision** - ускорение обучения на GPU с AMP
- ✅ **Переход к реальным картам** - архитектура готова для работы с городскими картами

## 📊 Рекомендации по Обучению

### Гиперпараметры

| Параметр | Рекомендуемое значение | Комментарий |
|----------|------------------------|-------------|
| **Batch Size** | 32-64 | Зависит от памяти GPU (16GB+ для 64) |
| **Эпохи** | 50-100 | С early stopping обычно хватает 30-60 |
| **Learning Rate** | 1e-4 | Начальный LR, уменьшается scheduler'ом |
| **Samples per Epoch** | 50,000 | Минимум для хорошего качества |
| **Всего лабиринтов** | 200K-500K | Для production рекомендуется 500K+ |
| **Размеры лабиринтов** | 33-77 | Нечетные числа |
| **Patience** | 10 | Эпох без улучшения до остановки |

### Быстрый старт

```bash
# Обучение с настройками по умолчанию (рекомендуется)
python train_maze_model.py

# Обучение с кастомными параметрами
python train_maze_model.py \
    --epochs 80 \
    --batch-size 48 \
    --lr 0.0001 \
    --samples-per-epoch 50000 \
    --size-min 33 \
    --size-max 77 \
    --patience 10

# Продолжение обучения с чекпоинта
python train_maze_model.py --resume
```

## 🏗️ Архитектура

### U-Net Model
```
Input (1, H, W)
    ↓
Downsampling: [32 → 64 → 128 → 256]
    ↓
Bottleneck: 512 channels
    ↓
Upsampling: [256 → 128 → 64 → 32] + skip connections
    ↓
Output (1, H, W) - маска пути
```

### Алгоритмы Генерации
1. **Prim** - быстрая генерация, хорошие лабиринты
2. **Kruskal** - равномерное распределение путей
3. **Eller** - эффективен для больших размеров
4. **Aldous-Broder** - максимально случайные лабиринты

## 🔄 Переход к Реальным Картам

Архитектура поддерживает работу с реальными картами:

### Примеры использования:
- 🏙️ **Карты городов** - здания/дороги → оптимальный маршрут
- 🗺️ **Навигационные карты** - граф дорог → путь между точками
- 🏢 **Карты помещений** - план здания → эвакуационный путь
- 🎮 **Игровые карты** - terrain → путь персонажа

### Как адаптировать:

```python
from train_maze_model import RealMapDataset, UNet, train, TrainingConfig

# 1. Подготовьте данные в формате .npy
# input_map.npy - карта (0=проходимо, 1=препятствие)
# route_map.npy - целевой маршрут (0=нет пути, 1=путь)

# 2. Создайте датасет
dataset = RealMapDataset(
    data_dir="path/to/real_maps",
    image_suffix="_input.npy",
    target_suffix="_route.npy",
    augment=True
)

# 3. Используйте ту же модель U-Net
model = UNet(in_channels=1, out_channels=1)

# 4. Обучайте как обычно
config = TrainingConfig(
    samples_per_epoch=10000,  # Меньше, т.к. реальные данные
    batch_size=32,
    num_epochs=100
)
```

## 📈 Интерпретация Результатов

### Метрики качества:
- **F1 Score > 0.8** - отличное качество
- **F1 Score 0.6-0.8** - хорошее качество
- **F1 Score < 0.6** - требуется дообучение

### Графики обучения:
- `Loss` - должен уменьшаться и стабилизироваться
- `Train-Val F1 Gap` - разница < 0.1 желательна
- `Learning Rate` - уменьшается по расписанию

### Troubleshooting:

| Проблема | Решение |
|----------|---------|
| F1 не растет | Увеличить LR до 1e-3, проверить pos_weight |
| Переобучение | Увеличить аугментацию, добавить Dropout |
| Мало памяти | Уменьшить batch_size до 16 |
| Долгое обучение | Использовать GPU, mixed precision уже включен |

## 🔬 Технические Детали

### Dynamic Pos Weight
Автоматически рассчитывается для баланса классов:
```python
pos_weight = total_neg / total_pos  # Обычно 50-500
```

### Collate Function
Поддерживает разные размеры в батче через padding до максимального.

### Worker Initialization
Каждый worker DataLoader имеет уникальный seed для разнообразия данных.
