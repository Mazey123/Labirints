# Переход к реальным картам: Инструкция

## Созданные файлы

1. **`real_map_config.py`** - Конфигурация для работы с реальными картами
2. **`real_map_dataset.py`** - Dataset и DataLoader для загрузки реальных изображений
3. **`train_real_maps.py`** - Скрипт для дообучения модели на реальных данных
4. **`evaluate_real_maps.py`** - Оценка модели на реальных картах

## Структура данных

Создайте следующую структуру папок (уже создана автоматически):

```
data/real_maps/
├── train/
│   ├── images/    # Исходные изображения лабиринтов
│   └── masks/     # Бинарные маски проходов
└── val/
    ├── images/
    └── masks/
```

### Требования к данным:

- **Изображения**: Любые форматы (PNG, JPG, BMP)
- **Маски**: Чёрно-белые изображения где:
  - Белый (255) = проход
  - Чёрный (0) = стена
- Имена файлов в `images/` и `masks/` должны совпадать

## Пошаговый процесс

### Шаг 1: Подготовка данных

1. Соберите реальные изображения карт/лабиринтов
2. Разметьте их (создайте бинарные маски):
   - Вручную в графическом редакторе (Photoshop, GIMP)
   - Или используйте полуавтоматические инструменты

3. Разделите данные:
   - 70-80% в `train/`
   - 20-30% в `val/`

### Шаг 2: Тестирование текущей модели

Проверьте как модель, обученная на синтетике, работает на реальных данных:

```bash
python evaluate_real_maps.py
```

Положите тестовое изображение как `test_real_map.png` или укажите путь в скрипте.

### Шаг 3: Дообучение (Fine-tuning)

Запустите дообучение модели на реальных данных:

```bash
python train_real_maps.py
```

Скрипт:
- Загрузит веса из `maze_model_best_f1.pth` (обученные на синтетике)
- Дообучит модель на ваших реальных картах
- Сохранит лучшую модель в `models_real_maps/real_map_best_iou.pth`

### Шаг 4: Оценка результатов

После дообучения оцените новую модель:

```bash
# Отредактируйте evaluate_real_maps.py, изменив:
# MODEL_PATH = "models_real_maps/real_map_best_iou.pth"

python evaluate_real_maps.py
```

## Настройки конфигурации

Отредактируйте `real_map_config.py` для изменения параметров:

```python
IMG_SIZE = 256          # Размер изображения
BATCH_SIZE = 8          # Размер батча
LEARNING_RATE = 1e-4    # Learning rate для дообучения
EPOCHS = 50             # Количество эпох
```

## Рекомендации

1. **Начните с малого**: 20-50 размеченных изображений для начала
2. **Аугментация**: Включена по умолчанию (повороты, отражения)
3. **Learning Rate**: Используется меньший LR (1e-4) для тонкой настройки
4. **Контроль качества**: Следите за метриками IoU и F1 в процессе обучения

## Возможные проблемы

| Проблема | Решение |
|----------|---------|
| Низкое качество | Увеличьте датасет, усильте аугментацию |
| Переобучение | Добавьте dropout, уменьшите LR, увеличьте датасет |
| Модель не сходится | Проверьте правильность масок, нормализацию |
